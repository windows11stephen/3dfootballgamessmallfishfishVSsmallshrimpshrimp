一句话说明：本游戏没有账号系统，不收集姓名、手机号、身份证、精确位置、通讯录、照片或生物识别信息。昵称、成绩和联机房间信息只用于游戏功能；其中排行榜内容是公开的，请不要填写真实个人信息。

本隐私政策说明「鱼虾游戏足球大战」（以下简称“本游戏”或“我们”）在你使用游戏、联机对战、排位榜、举报与支持功能时，如何处理相关信息。本游戏是独立开发者制作的、非官方的足球游戏，与任何联赛、协会、俱乐部、球员、游戏公司或平台无关联。

1. 我们收集什么、为什么收集

1.1 只保存在你设备上的信息

以下信息使用浏览器或 Windows 应用的本地存储（localStorage / IndexedDB）保存在你的设备上，不会由我们主动上传到服务器：

  • 游戏设置：键位、音量、镜头、触屏/键盘模式、难度选择。
  • 本地昵称：你在排位或联机面板输入的昵称，最多 10 个字符。
  • 本地成绩：本机最高分、进球数、失球数、赛季、时间戳。
  • 随机玩家 ID：形如 p 加随机字符的标识，用于合并同一设备的多场成绩，不包含你的真实身份。
  • 安装与缓存状态：Service Worker 缓存、页面资源，用于离线进入菜单和加载游戏。

清除方法：在浏览器中清除本站点的存储；在 Windows 应用中可通过“设置 → 应用 → 已安装的应用 → 鱼虾游戏足球大战 → 高级选项 → 重置/清除数据”，或卸载应用。

1.2 联机对战时的信息

联机使用 WebRTC 点对点连接和公共 MQTT 信令中继。为了建立房间和连接，以下信息会在参与者之间或通过公共中继传输：

  • 你输入的昵称、4 位房间号、房间模式（11v11 / 3v3）。
  • WebRTC 协商所需的网络信息，例如 IP 地址、NAT/ICE 候选、连接端口和会话标识。这些是建立 P2P 连接所必需的技术信息。
  • 房间公告、加入/离开消息、比赛开始/结束等控制消息。

我们没有自建游戏服务器，不保存联机对局内容、聊天记录或比赛回放。公共 MQTT 中继由第三方运营，可能按其隐私政策记录连接 IP、时间和技术日志。联机消息不是端到端加密的，请不要在昵称或房间公告中填写密码、住址、电话等敏感信息。

1.3 排行榜信息

当你参加排位赛并提交成绩时，以下内容会发布到公共 MQTT 的 retained 主题，并可被任何访问该主题的人读取：

  • 昵称（最多 10 个字符）、分数、进球数、失球数、赛季、提交时间、随机玩家 ID。

请注意：排行榜是公开榜单。昵称会显示在游戏内和 ranking.html 页面。请不要使用真实姓名、学校、住址、电话号码、微信号或其他可识别你身份的内容作为昵称。我们不会将排行榜内容用于广告、画像或出售。

你可以随时停止提交成绩；已发布的 retained 消息可按照第 6 节申请删除，我们会向对应主题发布空消息以清除该条记录。但我们无法控制其他玩家、搜索引擎、公共中继或第三方缓存已经形成的副本。

1.4 举报、申诉与支持

如果你通过 GitHub Issues 或举报页面提交内容，我们会收到你主动填写的信息，例如举报类型、被举报昵称、发生时间、描述，以及你选择留下的联系方式。我们只把这些信息用于处理举报、申诉、安全维护和回复你本人。

通过 GitHub Issues 提交的内容默认是公开的，其他 GitHub 用户可以看到。请不要在公开 Issue 中填写电话、住址、身份证号、他人隐私或未成年人信息。需要私下沟通时，请使用举报页面提供的邮件方式，并只提供处理问题所必需的信息。

1.5 我们不收集的信息

本游戏不要求注册账号，不收集：姓名、手机号、身份证号、精确地理位置、通讯录、短信、相册、麦克风、摄像头、健康数据、生物识别信息、广告标识符或跨站跟踪数据。游戏中的球员头像为内置美术素材，不是用户上传的照片，也不进行人脸识别。

2. Cookie 与类似技术

本游戏不使用广告 Cookie、跨站跟踪 Cookie 或第三方统计分析 SDK。我们仅使用 localStorage / IndexedDB 和 Service Worker 缓存来实现游戏设置、成绩保存和离线加载。这些本地数据不会自动发送给我们；你可以通过清除站点数据删除。

3. 第三方服务

为了实现托管、联机、排行榜和分发，本游戏会接触以下第三方。它们有各自的隐私政策，建议你查阅：

服务用途可能处理的信息
GitHub Pages（GitHub, Inc.）托管网页版游戏访问 IP、浏览器信息、请求日志，按 GitHub 隐私声明处理
公共 MQTT 中继（HiveMQ Public Broker、EMQX Public Broker、Eclipse Mosquitto 等）联机信令、公开房间列表、排行榜 retained 主题连接 IP、客户端 ID、主题与消息内容、时间与技术日志
WebRTC / STUN 服务建立玩家之间的点对点连接IP 地址、NAT/ICE 候选、连接元数据
Microsoft Store（如你从商店安装）应用分发、更新、商店遥测与购买（本游戏本身免费）由 Microsoft 按其隐私声明处理；我们不会收到你的支付信息

参考：GitHub 隐私声明；HiveMQ 隐私政策；EMQX 隐私政策；Microsoft 隐私声明。

4. 数据保留

  • 本地数据：保留在你的设备上，直到你清除站点数据、重置应用或卸载。
  • 联机消息：我们不做持久化保存；公共中继的保留时间由各中继运营商决定。
  • 排行榜 retained 消息：保留到被新成绩覆盖、发布空消息删除，或公共中继清理该主题。
  • 举报/支持信息：处理完毕后最多保留 24 个月，用于安全审计和重复问题处理；到期后删除或匿名化。法律另有要求的除外。

5. 数据安全

网页版通过 HTTPS 提供；我们不在游戏中保存密码或支付信息。由于联机采用公共 MQTT 信令和 WebRTC，昵称、房间号、成绩等信息可能被同一主题的其他人看到，无法保证私密性。请只提交你愿意公开的内容。

6. 你的权利

  • 访问/更正：你可以在游戏内查看和修改昵称、键位与本地成绩。
  • 删除本地数据：清除浏览器站点数据，或在 Windows 应用中重置/卸载。
  • 删除公开榜单记录：请通过 举报与申诉页面 或 GitHub Issues 提交你的随机玩家 ID、昵称和赛季；我们核实后会向对应 retained 主题发布空消息。请注意，我们无法删除其他玩家或第三方已经保存的副本。
  • 撤回同意：停止使用联机/排位功能，或不再提交成绩。撤回不影响此前已经公开的内容。

7. 儿童与未成年人

本游戏的商店年龄分级为 12+。未满 13 岁的用户请在监护人同意和指导下使用，并且不要单独使用联机、排行榜、举报或任何需要提交信息的功能。若你已满 13 岁但未满 18 岁，也请避免在昵称或举报内容中透露学校、住址、联系方式等个人信息。

8. 跨境传输

GitHub Pages 和部分公共 MQTT 中继可能位于中国大陆以外。使用网页版、联机或排行榜功能，意味着相关技术信息可能在你所在地区之外的服务器上处理。若你不希望发生这种传输，请仅使用单机模式，不进入联机或排位。

9. 政策更新

我们可能因功能、第三方服务或法律要求更新本政策。更新后会修改页面顶部的生效日期和版本号；涉及重大变化时，我们会在游戏菜单或更新说明中提示。继续使用即表示你接受更新后的政策。

10. 联系我们

隐私问题、数据删除、举报申诉：

  • GitHub Issues：提交 Issue（公开）
  • 举报与申诉页面：report.html
  • 备用邮箱：windows11stephen@users.noreply.github.com

我们通常在 7 个工作日内回复；复杂问题可能需要更长时间。请勿发送身份证、银行卡、密码或他人隐私。

English summary

This is an independent, non-official 3D football game. We do not require an account and do not collect names, phone numbers, government IDs, precise location, contacts, photos, or biometric data.

Local settings, nicknames, scores, and a random player ID are stored on your device. Online play uses WebRTC and public MQTT brokers; nicknames, room codes, IP/ICE connection data, and control messages may be visible to other participants or broker operators. Leaderboard entries (nickname, score, season, timestamp, random ID) are published to public retained MQTT topics and are visible to anyone. Do not use real personal information as a nickname.

We do not sell data or use advertising/tracking cookies. GitHub Pages, public MQTT brokers, WebRTC/STUN services, and Microsoft Store process technical data under their own privacy policies. Local data can be cleared in the app/browser. To request deletion of a public leaderboard entry, contact us with the random player ID, nickname, and season via the report page or GitHub Issues. We cannot delete copies held by other players or third parties.
