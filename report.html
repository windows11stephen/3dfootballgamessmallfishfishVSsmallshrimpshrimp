请先阅读：如果你或他人正面临人身危险、骚扰、诈骗或未成年人侵害，请优先联系当地紧急服务或公安机关，不要等待游戏内举报。请勿在举报中转发违法内容本身，也不要填写身份证、银行卡、密码、住址等敏感信息。

本页面用于举报联机房间、昵称、排行榜记录中的不当内容，或对处理结果提出申诉，也可提交版权/商标/肖像权等侵权投诉。提交前请阅读行为准则。虚假举报、批量举报或利用举报骚扰他人同样违反准则。

推荐方式：点击下方按钮生成一份结构化举报，并打开 GitHub Issues 提交页。GitHub Issue 是公开的；如果你需要私下沟通，请使用“复制举报内容”后发送邮件，不要在公开 Issue 中填写隐私。

GitHub Issues 需要 GitHub 账号；没有账号也可以使用邮件方式。我们通常在 7 个工作日内回复。

我们如何处理

  • 核实举报内容与上下文，必要时联系被举报人或要求补充信息。
  • 根据严重程度采取提醒、昵称过滤、移除榜单记录、限制联机或暂停功能。
  • 涉及版权/商标/肖像权的投诉，我们会核对权利证明，并可能先隐藏相关内容再进一步处理。
  • 处理完毕后通过你留下的联系方式回复；没有联系方式时，可能在原 Issue 中公开回复。

我们可能保留必要记录用于安全审计和重复问题处理，具体见隐私政策第 4 节。

申诉

如果你认为处理结果有误，请在同一 Issue 中回复，或新建 Issue 并标注“申诉”，提供原举报链接/编号、处理时间和需要复核的理由。请不要重复提交相同内容。
