快速结论：本游戏免费，无内购。网页版可安装为 PWA；Windows 版通过 Microsoft Store 安装。单机模式不需要联网；联机和排位需要能访问公共 MQTT/STUN 的网络。

常见问题

1. 怎么安装到 Windows？

从 Microsoft Store 搜索并安装「zhuj杯 2026」。安装后从开始菜单启动。首次启动需要能访问游戏的托管地址以下载页面资源；之后 Service Worker 会缓存核心文件，断网也能进入菜单和单机模式。

网页版也可以在浏览器地址栏点击“安装”或使用游戏菜单里的“📲 安装到本机”。

2. 断网能玩吗？

可以进入菜单、调整设置和进行单机比赛。首次访问需要联网加载；联机、排位提交和排行榜刷新需要网络。若页面提示离线，请先联网打开一次，让缓存完成。

3. 联机连不上 / 房间没人 / 一直转圈？

  • 确认双方都能访问公共 MQTT 中继；部分校园网、公司网或运营商可能拦截 WebSocket。
  • NAT 类型严格时 WebRTC 直连可能失败；可尝试换网络、关闭代理/VPN，或让房主重建房间。
  • 公共中继是第三方免费服务，可能临时不可用；稍后重试或换时间段。
  • 房间号是 4 位；确认朋友输入的是当前房间号，而不是旧房间号。

4. 排行榜不更新 / 看不到我的成绩？

排行榜通过公共 MQTT retained 主题同步，可能延迟或暂时连不上。先点“刷新榜单”；如果仍看不到，检查昵称是否填写、是否完成了整场比赛，以及网络是否能访问公共中继。榜单只保留同一玩家的最高分。

5. 怎么删除我的数据？

  • 本地设置/成绩：浏览器清除本站点数据；Windows 应用在“设置 → 应用 → 已安装的应用 → zhuj杯 2026 → 高级选项 → 重置/清除数据”，或卸载。
  • 公开榜单记录：通过举报与申诉页面提交随机玩家 ID、昵称和赛季，我们会向对应 retained 主题发布空消息。我们无法删除其他玩家或第三方已经保存的副本。

6. 游戏闪退 / 黑屏 / 卡顿？

  • 更新显卡驱动，确认浏览器或 Windows 已更新。
  • 关闭占用 GPU 的程序；在游戏设置里降低画质或关闭夜场。
  • 清除站点缓存后重新加载；如果仍失败，请附上设备型号、系统版本、浏览器版本和复现步骤提交 Issue。

没有。本游戏免费，不含内购、订阅、广告、抽奖或账号交易。游戏内解锁内容仅在本机生效，不能兑换现金。

English support summary

The game is free, with no in-app purchases, ads, or subscriptions. The web version can be installed as a PWA; the Windows version is distributed via Microsoft Store. Single-player works offline after the first online load; online play and leaderboards require network access to public MQTT/STUN services.

If online play fails, check WebSocket access, NAT/firewall settings, and try another network. Leaderboards may be delayed or unavailable when public brokers are down. To delete local data, clear site data or reset/uninstall the Windows app. To request deletion of a public leaderboard entry, use the report page with your random player ID, nickname, and season.
